## اسناد هر رابطه

فهرست کامل 105 جدول/نما و لینک مستند هرکدام در [README این snapshot](README.md) قرار دارد. فایل‌های رابطه، فرادادهٔ ساختاری و توضیح‌هایی را نشان می‌دهند که از کاتالوگ، قیدها، migration یا کد قابل پشتیبانی‌اند. وجود ستون به معنای نیاز محصولی یا قابل‌ویرایش بودن آن نیست.

## نقش‌ها و حدود داده

- **مسافر:** اطلاعات سفر و برنامهٔ سفر خودش را در رابط مسافر وارد می‌کند. وضعیت‌ها و ردیف‌های session، MFA، migration و کنترل عملیاتی فرم عمومی نیستند.
- **شرکت:** اطلاعات سازمان/خدمت و داده‌های تجاری خودش را در `/partners` نگهداری می‌کند؛ مجوز API و RLS باید سازمان جاری را محدود کند.
- **بازبین/مالک:** فقط از مسیر کنترل‌شده و capabilityهای مجزا به بازبینی دسترسی دارد. ثبت‌نام عادی مجوز مدیریتی نمی‌دهد.
- **سامانه:** hashها، زمان‌ها، شناسه‌ها، provenance، publication state و audit از سرور/روند اپراتوری می‌آیند؛ فرم عمومی برای ویرایش مستقیم آن‌ها وجود ندارد.
- **extension/PostGIS و viewها:** مرجع رسمی extension یا lineage در مستند هر رابطه آمده است؛ معنای تجاری تکراری برای آن‌ها ساخته نشده است.

## محدودیت‌های تأیید

در این snapshot تعداد 1,132 رخداد ستون در 105 رابطه دیده می‌شود؛ 902 مورد بدون توضیح واژه‌نامه‌ای‌اند. این عدد رخدادهای تکراری view، system و extension را دربر می‌گیرد و **نیازمندی یا پارامتر تجاری نیست**. ضرورت معماری برای همهٔ اشیا تأیید نشده و موارد نامعلوم باید نامعلوم بمانند.
