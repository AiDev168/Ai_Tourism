# knowledge.source_registry_registration_events

- **دیتابیس:** `rahgard_pilot_vps_staging`
- **نوع شیء:** جدول معمولی
- **شرح:** نیازمند توضیح دامنه‌ای تأییدشده از کد و مالک محصول
- **دسترسی خواندن:** از RLS/GRANT واقعی و مسیر API تطبیق شود؛ این مستند مقدار ردیفی نمی‌خواند.
- **دسترسی نوشتن:** از RLS/GRANT واقعی و مسیر API تطبیق شود؛ دسترسی مستقیم SQL به کاربر ندهید.
- **نمایش عمومی:** نامشخص تا تطبیق با View انتشار و API؛ پیش‌فرض خصوصی.
- **API مدل/مسیر:** مسیر مشخصی در کد پیدا نشده؛ نیازمند بررسی مالک ماژول.
- **فیلد فرم UI:** فرم مشخصی در فهرست نگاشت پیدا نشده؛ نیازمند بررسی UI.
- **منبع:** PostgreSQL `pg_catalog`، تراکنش فقط‌خواندنی، استخراج‌شده در `2026-11-24T06:58:13Z`
- **امنیت ردیفی (RLS):** روشن؛ Forced=خیر
- **هشدار:** هیچ دادهٔ ردیفی، رمز، کوکی یا مقدار شخصی در این فایل استخراج نشده است.

## محدودیت‌ها و ارتباط‌ها

- **source_registry_registration_events_page_title_check** (`c`): `CHECK (((length(btrim(page_title)) >= 1) AND (length(btrim(page_title)) <= 500)))`
- **source_registry_registration_events_policy_version_check** (`c`): `CHECK (((length(btrim(policy_version)) >= 1) AND (length(btrim(policy_version)) <= 80)))`
- **source_registry_registration_events_publisher_check** (`c`): `CHECK (((length(btrim(publisher)) >= 1) AND (length(btrim(publisher)) <= 240)))`
- **source_registry_registration_events_registered_url_check** (`c`): `CHECK ((registered_url ~ '^https://[^[:space:]]+$'::text))`
- **source_registry_registration_events_registration_note_check** (`c`): `CHECK (((length(btrim(registration_note)) >= 1) AND (length(btrim(registration_note)) <= 1000)))`
- **source_registry_registration_events_registrar_user_id_fkey** (`f`): `FOREIGN KEY (registrar_user_id) REFERENCES identity.users(user_id) ON DELETE RESTRICT`
- **source_registry_registration_events_source_id_fkey** (`f`): `FOREIGN KEY (source_id) REFERENCES knowledge.knowledge_sources(source_id) ON DELETE RESTRICT`
- **source_registry_registration_events_pkey** (`p`): `PRIMARY KEY (registration_id)`

## نیازمندی تکمیل دامنه

- تعداد ستون‌های فاقد شرح صریح: **10** از **10**.
- مالک دامنه و توسعه‌دهنده باید تعریف تجاری، مقادیر مجاز، واحد پول/اندازه، مثال غیرواقعی، قواعد اعتبارسنجی و سطح دسترسی هر فیلد را از کد و API تأیید کنند.
- ستون‌ها را با فرم عمومیِ ویرایش SQL در اختیار کاربر قرار ندهید. فرم‌ها باید براساس نقش/قرارداد API باشند.
