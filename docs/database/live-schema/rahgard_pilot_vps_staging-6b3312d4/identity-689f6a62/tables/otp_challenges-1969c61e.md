# identity.otp_challenges

- **دیتابیس:** `rahgard_pilot_vps_staging`
- **نوع شیء:** جدول معمولی
- **شرح:** نیازمند توضیح دامنه‌ای تأییدشده از کد و مالک محصول
- **دسترسی خواندن:** از RLS/GRANT واقعی و مسیر API تطبیق شود؛ این مستند مقدار ردیفی نمی‌خواند.
- **دسترسی نوشتن:** از RLS/GRANT واقعی و مسیر API تطبیق شود؛ دسترسی مستقیم SQL به کاربر ندهید.
- **نمایش عمومی:** نامشخص تا تطبیق با View انتشار و API؛ پیش‌فرض خصوصی.
- **API مدل/مسیر:** مسیر مشخصی در کد پیدا نشده؛ نیازمند بررسی مالک ماژول.
- **فیلد فرم UI:** فرم مشخصی در فهرست نگاشت پیدا نشده؛ نیازمند بررسی UI.
- **منبع:** PostgreSQL `pg_catalog`، تراکنش فقط‌خواندنی، استخراج‌شده در `2026-11-24T11:28:13Z`
- **امنیت ردیفی (RLS):** خاموش؛ Forced=خیر
- **هشدار:** هیچ دادهٔ ردیفی، رمز، کوکی یا مقدار شخصی در این فایل استخراج نشده است.

## محدودیت‌ها و ارتباط‌ها

- **otp_challenges_check** (`c`): `CHECK ((expires_at > created_at))`
- **otp_challenges_check1** (`c`): `CHECK ((resend_after >= created_at))`
- **otp_challenges_delivery_status_check** (`c`): `CHECK ((delivery_status = ANY (ARRAY['queued'::text, 'sent'::text, 'failed'::text])))`
- **otp_challenges_failed_attempts_check** (`c`): `CHECK (((failed_attempts >= 0) AND (failed_attempts <= 10)))`
- **otp_challenges_phone_e164_check** (`c`): `CHECK ((phone_e164 ~ '^\+989[0-9]{9}$'::text))`
- **otp_challenges_purpose_check** (`c`): `CHECK ((purpose = 'login'::text))`
- **otp_challenges_verifier_hmac_check** (`c`): `CHECK ((octet_length(verifier_hmac) = 32))`
- **otp_challenges_pkey** (`p`): `PRIMARY KEY (challenge_id)`

## ایندکس‌ها

- `idx_otp_challenges_cleanup`: `CREATE INDEX idx_otp_challenges_cleanup ON identity.otp_challenges USING btree (created_at, challenge_id)`
- `idx_otp_challenges_expiry`: `CREATE INDEX idx_otp_challenges_expiry ON identity.otp_challenges USING btree (expires_at) WHERE ((consumed_at IS NULL) AND (superseded_at IS NULL))`
- `idx_otp_challenges_phone_created`: `CREATE INDEX idx_otp_challenges_phone_created ON identity.otp_challenges USING btree (phone_e164, created_at DESC)`
- `otp_challenges_pkey`: `CREATE UNIQUE INDEX otp_challenges_pkey ON identity.otp_challenges USING btree (challenge_id)`

## نیازمندی تکمیل دامنه

- تعداد ستون‌های فاقد شرح صریح: **0** از **13**.
- مالک دامنه و توسعه‌دهنده باید تعریف تجاری، مقادیر مجاز، واحد پول/اندازه، مثال غیرواقعی، قواعد اعتبارسنجی و سطح دسترسی هر فیلد را از کد و API تأیید کنند.
- ستون‌ها را با فرم عمومیِ ویرایش SQL در اختیار کاربر قرار ندهید. فرم‌ها باید براساس نقش/قرارداد API باشند.
