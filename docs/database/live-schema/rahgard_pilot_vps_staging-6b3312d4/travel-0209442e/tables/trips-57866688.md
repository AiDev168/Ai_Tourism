# travel.trips

- **دیتابیس:** `rahgard_pilot_vps_staging`
- **نوع شیء:** جدول معمولی
- **شرح:** نیازمند توضیح دامنه‌ای تأییدشده از کد و مالک محصول
- **دسترسی خواندن:** از RLS/GRANT واقعی و مسیر API تطبیق شود؛ این مستند مقدار ردیفی نمی‌خواند.
- **دسترسی نوشتن:** از RLS/GRANT واقعی و مسیر API تطبیق شود؛ دسترسی مستقیم SQL به کاربر ندهید.
- **نمایش عمومی:** نامشخص تا تطبیق با View انتشار و API؛ پیش‌فرض خصوصی.
- **API مدل/مسیر:** مسیر مشخصی در کد پیدا نشده؛ نیازمند بررسی مالک ماژول.
- **فیلد فرم UI:** فرم مشخصی در فهرست نگاشت پیدا نشده؛ نیازمند بررسی UI.
- **منبع:** PostgreSQL `pg_catalog`، تراکنش فقط‌خواندنی، استخراج‌شده در `2026-11-24T06:58:13Z`
- **امنیت ردیفی (RLS):** خاموش؛ Forced=خیر
- **هشدار:** هیچ دادهٔ ردیفی، رمز، کوکی یا مقدار شخصی در این فایل استخراج نشده است.

## محدودیت‌ها و ارتباط‌ها

- **trips_budget_max_check** (`c`): `CHECK (((budget_max IS NULL) OR (budget_max >= (0)::numeric)))`
- **trips_budget_min_check** (`c`): `CHECK (((budget_min IS NULL) OR (budget_min >= (0)::numeric)))`
- **trips_budget_original_complete_check** (`c`): `CHECK ((((budget_amount_original IS NULL) AND (budget_currency_iso IS NULL) AND (budget_unit IS NULL) AND (budget_raw_text IS NULL)) OR ((budget_amount_original IS NOT NULL) AND (budget_currency_iso IS NOT NULL) AND (budget_currency_iso = 'IRR'::bpchar) AND (budget_unit IS NOT NULL) AND (budget_unit = ANY (ARRAY['rial'::text, 'toman'::text])) AND (budget_raw_text IS NOT NULL) AND (budget_amount_original >= (0)::numeric))))`
- **trips_check** (`c`): `CHECK (((end_date IS NULL) OR (start_date IS NULL) OR (end_date >= start_date)))`
- **trips_check1** (`c`): `CHECK (((budget_min IS NULL) OR (budget_max IS NULL) OR (budget_max >= budget_min)))`
- **trips_currency_check** (`c`): `CHECK ((currency ~ '^[A-Z]{3}$'::text))`
- **trips_duration_days_365_check** (`c`): `CHECK (((duration_days IS NULL) OR ((duration_days >= 1) AND (duration_days <= 365))))`
- **trips_extraction_confidence_check** (`c`): `CHECK (((extraction_confidence IS NULL) OR ((extraction_confidence >= (0)::numeric) AND (extraction_confidence <= (1)::numeric))))`
- **trips_traveler_count_check** (`c`): `CHECK (((traveler_count >= 1) AND (traveler_count <= 50)))`
- **trips_traveler_count_nullable_check** (`c`): `CHECK (((traveler_count IS NULL) OR ((traveler_count >= 1) AND (traveler_count <= 50))))`
- **trips_trip_status_check** (`c`): `CHECK ((trip_status = ANY (ARRAY['draft'::text, 'ready'::text, 'planned'::text, 'completed'::text, 'cancelled'::text, 'archived'::text])))`
- **trips_version_check** (`c`): `CHECK ((version > 0))`
- **trips_conversation_id_fkey** (`f`): `FOREIGN KEY (conversation_id) REFERENCES conversation.conversations(conversation_id) ON DELETE CASCADE`
- **trips_user_id_fkey** (`f`): `FOREIGN KEY (user_id) REFERENCES identity.users(user_id) ON DELETE CASCADE`
- **trips_pkey** (`p`): `PRIMARY KEY (trip_id)`

## تریگرهای غیرسیستمی

- `trg_enforce_trip_duration_against_itineraries`: `CREATE TRIGGER trg_enforce_trip_duration_against_itineraries BEFORE UPDATE OF duration_days ON travel.trips FOR EACH ROW EXECUTE FUNCTION travel.enforce_trip_duration_against_itineraries()`
- `trg_trip_request_revision_profile`: `CREATE TRIGGER trg_trip_request_revision_profile AFTER UPDATE OF confirmed_requirements ON travel.trips FOR EACH ROW EXECUTE FUNCTION partner.capture_trip_request_revision_from_trip()`

## نیازمندی تکمیل دامنه

- تعداد ستون‌های فاقد شرح صریح: **26** از **26**.
- مالک دامنه و توسعه‌دهنده باید تعریف تجاری، مقادیر مجاز، واحد پول/اندازه، مثال غیرواقعی، قواعد اعتبارسنجی و سطح دسترسی هر فیلد را از کد و API تأیید کنند.
- ستون‌ها را با فرم عمومیِ ویرایش SQL در اختیار کاربر قرار ندهید. فرم‌ها باید براساس نقش/قرارداد API باشند.
