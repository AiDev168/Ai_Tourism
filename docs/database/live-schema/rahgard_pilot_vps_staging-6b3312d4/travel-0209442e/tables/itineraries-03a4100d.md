# travel.itineraries

- **دیتابیس:** `rahgard_pilot_vps_staging`
- **نوع شیء:** جدول معمولی
- **شرح:** نیازمند توضیح دامنه‌ای تأییدشده از کد و مالک محصول
- **دسترسی خواندن:** از RLS/GRANT واقعی و مسیر API تطبیق شود؛ این مستند مقدار ردیفی نمی‌خواند.
- **دسترسی نوشتن:** از RLS/GRANT واقعی و مسیر API تطبیق شود؛ دسترسی مستقیم SQL به کاربر ندهید.
- **نمایش عمومی:** نامشخص تا تطبیق با View انتشار و API؛ پیش‌فرض خصوصی.
- **API مدل/مسیر:** مسیر مشخصی در کد پیدا نشده؛ نیازمند بررسی مالک ماژول.
- **فیلد فرم UI:** فرم مشخصی در فهرست نگاشت پیدا نشده؛ نیازمند بررسی UI.
- **منبع:** PostgreSQL `pg_catalog`، تراکنش فقط‌خواندنی، استخراج‌شده در `2026-11-24T11:28:13Z`
- **امنیت ردیفی (RLS):** خاموش؛ Forced=خیر
- **هشدار:** هیچ دادهٔ ردیفی، رمز، کوکی یا مقدار شخصی در این فایل استخراج نشده است.

## محدودیت‌ها و ارتباط‌ها

- **itineraries_day_count_365_check** (`c`): `CHECK (((day_count >= 1) AND (day_count <= 365)))`
- **itineraries_itinerary_status_check** (`c`): `CHECK ((itinerary_status = ANY (ARRAY['draft'::text, 'presented'::text, 'accepted'::text, 'edited'::text, 'archived'::text])))`
- **itineraries_revision_check** (`c`): `CHECK ((revision > 0))`
- **itineraries_title_by_locale_check** (`c`): `CHECK ((jsonb_typeof(title_by_locale) = 'object'::text))`
- **itineraries_version_check** (`c`): `CHECK ((version > 0))`
- **itineraries_recommendation_request_id_fkey** (`f`): `FOREIGN KEY (recommendation_request_id) REFERENCES recommendation.recommendation_requests(recommendation_request_id) ON DELETE SET NULL`
- **itineraries_trip_id_fkey** (`f`): `FOREIGN KEY (trip_id) REFERENCES travel.trips(trip_id) ON DELETE CASCADE`
- **itineraries_pkey** (`p`): `PRIMARY KEY (itinerary_id)`
- **itineraries_trip_id_version_key** (`u`): `UNIQUE (trip_id, version)`

## ایندکس‌ها

- `idx_itineraries_trip_version`: `CREATE INDEX idx_itineraries_trip_version ON travel.itineraries USING btree (trip_id, version DESC)`
- `itineraries_pkey`: `CREATE UNIQUE INDEX itineraries_pkey ON travel.itineraries USING btree (itinerary_id)`
- `itineraries_trip_id_version_key`: `CREATE UNIQUE INDEX itineraries_trip_id_version_key ON travel.itineraries USING btree (trip_id, version)`

## سیاست‌های RLS

- سیاستی در `pg_policy` ثبت نشده یا برای این شیء صدق نمی‌کند.

## تریگرهای غیرسیستمی

- `trg_enforce_itinerary_duration`: `CREATE TRIGGER trg_enforce_itinerary_duration BEFORE INSERT OR UPDATE OF trip_id, day_count ON travel.itineraries FOR EACH ROW EXECUTE FUNCTION travel.enforce_itinerary_duration()`
- `trg_trip_request_revision_itinerary`: `CREATE TRIGGER trg_trip_request_revision_itinerary AFTER UPDATE ON travel.itineraries FOR EACH ROW EXECUTE FUNCTION partner.capture_trip_request_revision_from_itinerary()`

## نیازمندی تکمیل دامنه

- تعداد ستون‌های فاقد شرح صریح: **0** از **12**.
- مالک دامنه و توسعه‌دهنده باید تعریف تجاری، مقادیر مجاز، واحد پول/اندازه، مثال غیرواقعی، قواعد اعتبارسنجی و سطح دسترسی هر فیلد را از کد و API تأیید کنند.
- ستون‌ها را با فرم عمومیِ ویرایش SQL در اختیار کاربر قرار ندهید. فرم‌ها باید براساس نقش/قرارداد API باشند.
