# PWA Design Package

The visual design package defines the owner-approved experience direction for the AI Tourism PWA.

- [PWA Visual Design Brief v0.1](PWA_VISUAL_DESIGN_BRIEF_v0.1.md) — binding Phase 1 art direction, palette, Persian typography, photography rules, responsive page layouts, motion, performance, WCAG 2.2 AA and visual sign-off checklist.

The direction is **Contemporary Iranian Travel Editorial**: refined and image-led, distinctly Persian, generous with space, warm in material and color, and highly legible. It must feel like a premium travel product rather than a generic dashboard or AI chat clone.

Phase 1 should establish the design system and visual shell, not implement every later product interaction. Use the brief as the acceptance source for screenshots, accessibility and performance review.

- [Image and font asset credits](IMAGE_FONT_ASSET_CREDITS.md) — source pages, authors, licenses and delivery notes for the visual refresh.
